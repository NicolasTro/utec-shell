# Shell, init files, variables and expansions

Este directorio contiene scripts de Bash para aprender sobre archivos de inicialización, variables locales y globales, y expansiones en el Shell de Unix.

## Descripción de los scripts

- `0-alias`: Crea un alias llamado `ls` con el valor `rm *`.
- `1-hello_you`: Imprime en pantalla `hello user`, donde `user` es el usuario actual de Linux.
- `2-path`: Agrega `/action` al final de la variable de entorno `PATH`.
- `3-paths`: Cuenta y muestra el número de directorios contenidos en la variable `PATH`.
- `4-global_variables`: Lista todas las variables de entorno (globales).
- `5-local_variables`: Lista todas las variables locales, variables de entorno y funciones del shell.
- `6-create_local_variable`: Crea una variable local llamada `BEST` con el valor `School`.
- `7-create_global_variable`: Crea una variable de entorno llamada `BEST` con el valor `School`.
- `8-true_knowledge`: Imprime el resultado de la suma de 128 con el valor de la variable de entorno `TRUEKNOWLEDGE`.
- `9-divide_and_rule`: Imprime el resultado de la variable `POWER` dividida por `DIVIDE`.
- `10-love_exponent_breath`: Imprime el resultado de `BREATH` elevado a la potencia de `LOVE`.
- `11-binary_to_decimal`: Convierte un número en base 2 (almacenado en `BINARY`) a base 10.
- `12-combinations`: Muestra todas las combinaciones posibles de dos letras de la 'a' a la 'z', excepto 'oo', ordenadas alfabéticamente.
- `13-print_float`: Imprime el número almacenado en la variable `NUM` con dos decimales.
- `14-decimal_to_hexadecimal`: Convierte un número en base 10 (almacenado en `DECIMAL`) a base 16 en minúsculas.
